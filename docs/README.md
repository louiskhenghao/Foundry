# Foundry docs

Three folders, one for each kind of reader.

| Folder | For | Start with |
|---|---|---|
| [guide/](guide/) · [中文](guide/README.zh.md) | people who use Foundry through the web UI | [What Foundry does](guide/README.md), then [Your first goal](guide/your-first-goal.md) |
| [operate/](operate/) | whoever installs, configures and updates Foundry | [Install](operate/install.md) |
| [develop/](develop/) | people who change Foundry's code | [Architecture](develop/architecture.md) |

Both Claude Code and Codex use the same goal workflow. For independent accounts, ChatGPT-only Codex sign-in, presets and current capability differences, start with [Codex operation](operate/codex.md). Existing installations should read [upgrade and rollback](operate/updates-and-backup.md#upgrading-to-mixed-provider-goals); contributors can inspect the [validation record](develop/codex-validation.md).

The words Foundry uses (Goal, Brief, Milestone, Model Preset …) are defined in the [glossary](../CONTEXT.md).
