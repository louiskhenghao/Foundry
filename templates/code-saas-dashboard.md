## Already decided
- Every metric has one definition in code, tested against hand-computed fixtures, and the dashboard shows that definition on hover; two charts never disagree about the same number.
- Aggregates are precomputed into summary tables (or materialised views) on a schedule that matches the freshness above; the page never runs a full scan per request, and every page loads under two seconds on a year of data.
- Authorisation is enforced in the query layer by role, not hidden in the UI; a test proves a manager cannot read another shop's revenue through any endpoint.
- Charts are accessible: each has a title, a text summary and a table view; colours pass contrast and do not carry meaning alone.
- Date handling is explicit about time zones (the shop's, shown in the header) and about incomplete current periods.
- Exports and the digest are generated by the same code as the screens, so the numbers match to the cent.
- Loading, empty and error states are designed, not left to chance; the milestone script walks a filter, a drill-down and an export.
